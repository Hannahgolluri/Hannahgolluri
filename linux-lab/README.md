# 🐧 Linux Command Line Fundamentals Lab

## Overview
This lab focuses on basic Linux command-line operations and system navigation skills used in cloud and IT environments.

## Objectives
- Navigate Linux file system
- Create and manage files and directories
- Understand file permissions
- Use basic terminal commands

## Commands Practiced
- ls (list files)
- pwd (print working directory)
- mkdir (create directories)
- touch (create files)
- chmod (change permissions)

## Skills Developed
- Linux terminal navigation
- File and directory management
- Basic system administration concepts
- Command-line efficiency
