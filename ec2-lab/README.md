# ☁️ AWS EC2 Instance Deployment Lab

## Overview
This project demonstrates hands-on experience with launching and configuring an Amazon EC2 instance using AWS Management Console.

## Objectives
- Launch an EC2 instance
- Configure security groups for SSH access
- Connect to a Linux instance using SSH
- Understand cloud compute infrastructure

## Steps Performed
1. Logged into AWS Management Console
2. Navigated to EC2 dashboard
3. Launched a new EC2 instance (Amazon Linux)
4. Configured instance type and key pair
5. Set up security group to allow SSH (port 22)
6. Successfully launched and connected to instance via SSH

## Skills Learned
- AWS EC2 fundamentals
- Cloud computing basics
- Security group configuration
- SSH connectivity
- Virtual server management
